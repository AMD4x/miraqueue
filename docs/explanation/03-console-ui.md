# Console UI and progress

The main menu keeps the public numeric workflows: 1 Apply, 2 Preview, 3 Full Mirror, 4 Paths, 5 Exclusions, 6 Clear Queue, 7 Settings, 8 Lifecycle and 9 Status. Pending counts distinguish Add/Update/Delete; destination errors remain visible rather than becoming an empty successful queue.

Preview uses paged tables and aggregates suitable new-directory entries into TREE jobs. Progress rows show status, pair, item, copied/total bytes, speed and ETA. The viewport follows active work without treating waiting mkdir/delete rows as completed. Byte formatting uses invariant decimal notation and binary units.

Console redraws fall back when output is redirected. `NoPause` permits noninteractive result inspection. It does not automatically answer lifecycle or Full Mirror confirmation questions. Demo GIFs are rendered from captured V2 function output; their menus and labels are generated by the implementation.
